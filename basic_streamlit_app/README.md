# 🐧Palmer's Penguins Streamlit app
This Streamlit app allows users to explore and compare the physical characteristics of the Palmer's Penguins dataset

## ✏️Description
This app 
- displays summary statistics for the dataset
- visualizes the relationship between flipper length and body mass by species
- compares selected physical characteristics across species using boxplots
- allows users to explore data for selected species

## 👨‍🏫Instructions
Once you are inside [basic_streamlit_app] folder, run the following command in the terminal:

streamlit run main.py
